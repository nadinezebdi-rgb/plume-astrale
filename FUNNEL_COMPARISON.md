## 🎯 PSYCHOLOGICAL FLOW COMPARISON

### BEFORE: Fear-Based (Negative)
```
User Journey Mental Model:

1. Landing     → "What is this?" 😕
2. Formulaire  → "Why so many fields?" 😤
3. Results     → "OK, now what?"
4. Free Q1     → "This is cool"
5. Free Q2     → "Wow, useful"
6. Limit       → "ONE MORE QUESTION?"
7. Paywall     → "WAIT, I have to PAY?!" 😡
8. Never Again → Customer Lost ❌
```

**Psychology:** Bait-and-switch feeling, user feels tricked

---

### AFTER: Trust-Based (Positive)
```
User Journey Mental Model:

1. Landing     → "FREE oracle? Let me try" 😊
2. Select Sign → "Easy, just 1 click"
3. Oracle Text → "Wow, this is REALLY good" 😲
4. Offer Packs → "Hmm, I want more... let me see options"
5. See Pricing → "OK, $15 for unlimited? That's fair"
6. Purchase    → "YES, let's do it" ✅
7. Chat Solena → "Wow, this AI understands ME"
8. Upsell      → "Sure, $15 for coaching? Worth it"
9. LTV 52€+    → Loyal customer for life 🎉
```

**Psychology:** Earned trust → organic upsell desire
