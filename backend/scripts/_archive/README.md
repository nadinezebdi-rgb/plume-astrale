# Scripts archivés — assets marketing générés une seule fois

Ces scripts ont servi à générer des assets marketing ponctuels (TikTok / Reels / voiceovers)
lors des campagnes de lancement d'août 2025. Ils sont conservés pour réutilisation éventuelle
mais ne sont plus référencés par le runtime.

- `assemble_demo_60s.py` — Assemblage démo 60s
- `assemble_tiktok_v2.py` / `assemble_tiktok_v3.py` — Compositions vidéo TikTok
- `capture_plume_shots.py` — Captures Playwright pour teasers
- `gen_demo_clips.py` — Génération de clips Sora
- `gen_demo_voiceover.py` / `gen_voiceover_tiktok.py` — Voice-over OpenAI TTS
- `gen_reels_teaser_15s.py` — Teaser Reels 15s
- `gen_tiktok_hooks_ab.py` — A/B test hooks TikTok
- `tiktok_burn_titles.py` / `tiktok_outils_montage.py` — Utilitaires ffmpeg pour incrustations

Pour rejouer : `python -m backend.scripts._archive.NOM_DU_SCRIPT`
